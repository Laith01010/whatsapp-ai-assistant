# بوت واتساب بالذكاء الاصطناعي — مركز فحص طبي (Demo)

بوت بيرد على زباين مركز فحص طبي على واتساب، بالعربي والإنجليزي، من معلومات المركز فقط، وبيحوّل للموظف لما يلزم.

**الأدوات:** n8n + WhatsApp Cloud API (Meta) + Gemini API (باقة مجانية)

---

## كيف بيشتغل

```
زبون يبعت رسالة
   ↓
WhatsApp Cloud API  →  Webhook (n8n)
   ↓
Parse Message   ← يفلتر الرسائل، يمنع التكرار، يجيب آخر المحادثة
   ↓
Ask Gemini      ← يجاوب من "قاعدة المعرفة" بس
   ↓
Process Reply   ← ينظّف الرد، يحفظ المحادثة، يقرر إذا لازم موظف
   ↓
Send WhatsApp Reply  →  الزبون
   ↓
Needs Human? ── نعم ──→ Notify Staff (رسالة للموظف فيها رقم الزبون وسؤاله)
```

ومنفصل عنه: **WhatsApp Verify (GET)** — Meta بتستخدمه مرة وحدة عشان تتأكد إن الـ webhook تبعك.

## خطوات التشغيل

### 1) n8n
- أسهل إشي: حساب تجريبي على **n8n Cloud**.
- أو على جهازك بـ Docker:
  ```bash
  docker run -it --rm -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
  ```
  ⚠️ إذا على جهازك، Meta لازم توصل للـ webhook من الإنترنت، فبتحتاج رابط عام (مثلاً **ngrok** أو **Cloudflare Tunnel**). عشان هيك n8n Cloud أسهل للـ demo.

- من n8n: **Workflows → Import from File** → اختار `whatsapp-ai-bot.n8n.json`.

### 2) مفتاح Gemini (مجاني)
- ادخل **aistudio.google.com** بحساب Gmail.
- اضغط **Get API key** → **Create API key**.
- الباقة المجانية كافية للـ demo. ملاحظة: بالباقة المجانية Google بتستخدم البيانات لتحسين منتجاتها، فما تستخدمها لبيانات زباين حقيقيين — للإنتاج بتفعّل الدفع.

### 3) واتساب (Meta)
1. ادخل **developers.facebook.com** → My Apps → Create App → نوع **Business**.
2. ضيف منتج **WhatsApp** للتطبيق.
3. من **WhatsApp → API Setup**:
   - انسخ **Temporary access token**.
   - انسخ **Phone number ID** (رقم طويل، مش رقم التلفون).
   - بقسم "To" ضيف **رقم تلفونك** كـ رقم تجربة، ووثّقه بالكود اللي بيوصلك.

> الـ token المؤقت بينتهي بعد فترة قصيرة. للـ demo تمام، بس للإنتاج بتعمل **System User token** دائم من Business Settings.

### 4) عبّي الإعدادات
افتح نود **Parse Message** وعدّل الـ `CONFIG` فوق:
```js
WHATSAPP_TOKEN:    'الـ token من Meta',
PHONE_NUMBER_ID:   'الـ Phone number ID',
GEMINI_API_KEY:    'مفتاح Gemini',
STAFF_NUMBER:      '9715XXXXXXXX',   // رقمك أنت للتجربة (بدون +)
```
وإذا بدك، غيّر `VERIFY_TOKEN` بنود **Verify Token** (أي كلمة بتختارها).

### 5) فعّل واربط الـ webhook
1. بـ n8n شغّل الـ workflow (**Publish** أو **Active** فوق يمين). ⚠️ أي تعديل بعدها بدّه **Publish** من جديد.
2. افتح نود **WhatsApp Incoming (POST)** وانسخ الـ **Production URL** (بيخلص بـ `/webhook/whatsapp`).
3. بـ Meta: **WhatsApp → Configuration → Webhook → Edit**:
   - **Callback URL** = الرابط اللي نسخته.
   - **Verify token** = `noor-demo-verify-123` (أو اللي غيرته).
   - اضغط **Verify and save**.
4. بنفس الصفحة، **Webhook fields** → اعمل **Subscribe** على `messages`.
5. **اربط حساب واتساب بالتطبيق** (مرة وحدة). بدونها Meta بتتحقق من الـ webhook بس **ما بتبعت الرسائل**:
   ```
   curl -X POST "https://graph.facebook.com/v26.0/WABA_ID/subscribed_apps" -H "Authorization: Bearer TOKEN"
   ```
   `WABA_ID` = معرّف حساب واتساب للأعمال (من صفحة API Setup). المفروض يرد `{"success":true}`.

### 6) جرّب
ابعت من تلفونك على رقم التجربة تبع Meta:
- "مرحبا، شو الأوراق المطلوبة؟"
- "How much is the express service?"
- "بدي احكي مع موظف" ← لازم يرد ويبعت تنبيه للـ STAFF_NUMBER.
- "النتيجة تبعتي طلعت؟" ← لازم يطلب رقم الطلب ويحوّل.

وبتشوف كل خطوة بـ n8n من **Executions**.

---

## تجربة بدون Meta (عشان تتأكد إن Gemini شغال)

قبل ما تربط واتساب، جرّب الجزء الخاص بالـ AI لحاله. (غيّر الـ `id` بالملف كل مرة، لأن البوت بيتجاهل الرسائل المكررة.)

```bash
curl -X POST "https://YOUR-N8N-URL/webhook/whatsapp" \
  -H "Content-Type: application/json" \
  -d @sample-message.json
```

بـ **Executions** بتشوف رد Gemini بنود **Process Reply**. نود الإرسال رح يفشل (لأن الرقم وهمي) وهاد طبيعي هون.

## تخصيصه لشركة حقيقية

كل معلومات المركز موجودة بمكان واحد: `KNOWLEDGE_BASE` بنود **Parse Message**. كل اللي فيها حالياً **بيانات تجريبية** (أسعار، أوقات، عنوان). بدّلها بمعلومات الشركة، والبوت فوراً بيصير يجاوب منها.

## قرارات تقنية (هاد اللي بيسألوك عنه بالمقابلة)

| القرار | ليش |
|---|---|
| الـ webhook بيرد **200 فوراً** | إذا Meta ما وصلها رد بسرعة، بتعيد إرسال الرسالة وبيصير رد مكرر |
| **منع التكرار** بالـ message ID | حتى لو Meta عادت الإرسال، البوت ما بيرد مرتين |
| تجاهل **status updates** | Meta بتبعت تحديثات (delivered/read) على نفس الـ webhook، وهاي مش رسائل |
| **قاعدة معرفة + قواعد صارمة** بالـ prompt | البوت ما بيخترع أسعار أو أوقات، وإذا ما بيعرف بيحوّل لموظف |
| **[HANDOFF]** tag | الـ AI بيقرر متى يحتاج إنسان، والكود بيشيل الكلمة قبل ما توصل للزبون |
| **ذاكرة محادثة** (آخر 6 تبادلات، 24 ساعة) | البوت بيفهم الأسئلة المتتابعة ("وكم سعره؟") |
| **Fallback** إذا الـ AI API وقع أو رجّع رد فاضي | الزبون بياخذ رد مهذب والموظف بياخذ تنبيه، بدل صمت |
| **gemini-3.5-flash-lite** | سريع ومجاني للتجربة، ومناسب لأسئلة متكررة بسيطة. بتقدر تغيّره لـ `gemini-3.8-flash` لجودة أعلى |
| ما بيقدم **نصائح طبية** ولا بيشوف نتائج | أمان قانوني، والبوت أصلاً ما عنده وصول لسجلات المرضى |

**شو بتضيف لو صار مشروع حقيقي:**
- تخزين المحادثات بقاعدة بيانات أو CRM بدل ذاكرة n8n.
- ربط بنظام المواعيد أو النتائج (API الشركة) عشان البوت يجاوب على حالة الطلب.
- **Message templates** معتمدة من Meta للرسائل بعد ما تخلص نافذة الـ 24 ساعة.
- نقل المفاتيح لـ **n8n Credentials** بدل كتابتها بالكود.
- لوحة تقارير: كم رسالة، كم تحويل، أكثر الأسئلة تكراراً.

## مشاكل شائعة

| المشكلة | الحل |
|---|---|
| Meta بتقول Verify failed | تأكد إن الـ workflow **Active**، وإنك نسخت **Production URL** مش Test URL، وإن الـ verify token متطابق |
| البوت ما بيرد | تأكد إنك عملت Subscribe على `messages`، وإن رقمك مضاف كرقم تجربة |
| `400` / `403` من Gemini | المفتاح غلط — انسخه من جديد من AI Studio |
| `429` من Gemini | تجاوزت حد الباقة المجانية — استنى دقيقة وجرّب |
| `401` أو `190` من Meta | الـ token المؤقت انتهى. خذ واحد جديد وحطه بـ Parse Message واعمل **Publish**. للإنتاج: System User token دائم |
| الـ webhook تحقق بس الرسائل ما بتوصل n8n | ناقص خطوة `subscribed_apps` (الخطوة 5 فوق) |
| تنبيه الموظف ما وصل | رقم الموظف لازم يكون مضاف كرقم تجربة، وبالعادة لازم يكون بعت رسالة للرقم خلال آخر 24 ساعة |
| البوت ما بيتذكر المحادثة | الذاكرة بتشتغل بس لما الـ workflow **Active** (مش بوضع Test) |

## للـ demo بالمقابلة

سجّل فيديو قصير (دقيقة لدقيقتين):
1. اسأل بالعربي عن الأوراق، والبوت بيرد.
2. اسأل بالإنجليزي عن السعر، والبوت بيرد بالإنجليزي.
3. "وكم بياخذ وقت؟" — البوت بيفهم إنك بتسأل عن نفس الخدمة.
4. "بدي موظف" — بتورجي التنبيه واصل على التلفون الثاني.
5. افتح n8n وورجيهم الـ workflow والـ Executions.

جملة للمقابلة: *"بنيت بوت بيجاوب على الأسئلة المتكررة من مصدر معلومات واحد بيتحدّث بسهولة، وبيحوّل للموظف لما يلزم، وما بيخترع معلومات."*
